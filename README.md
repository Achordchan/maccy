# Maccy

Maccy 是一个开源的剪贴板管理工具，专为 Windows 系统设计。它能够帮助用户更高效地管理和使用剪贴板中的内容，支持文本、图片和文件的捕获与粘贴。

## 主要特性

- **剪贴板历史记录**：自动保存剪贴板的历史内容，方便随时调用。
- **多格式支持**：支持文本、图片和文件的捕获与粘贴。
- **界面友好**：简洁直观的用户界面，易于操作。
- **快速搜索**：提供快速搜索功能，轻松找到需要的内容。
- **自动启动**：支持系统启动时自动运行。
- **更新检查**：内置更新检查功能，确保软件保持最新状态。

## 安装指南

### Windows

1. 下载最新版本的安装包。
2. 运行安装程序并按照提示完成安装。
3. 安装完成后，Maccy 将自动在系统托盘中显示图标。

## 使用说明

- **打开/关闭剪贴板窗口**：默认快捷键为 `Ctrl + alt + 2`。
- **搜索内容**：在剪贴板窗口中使用搜索框，输入关键词即可过滤内容。
- **应用内容**：点击历史记录中的条目，将其应用到当前活动的应用程序中。
- **编辑备注**：右键点击条目，选择“编辑备注”以添加描述信息。
- **固定条目**：右键点击条目，选择“固定”以防止其被自动清除。
- **删除条目**：右键点击条目，选择“删除”以移除不需要的内容。

## 设置

- **主题设置**：支持跟随系统、深色和浅色三种主题模式。
- **捕获设置**：可分别开启或关闭文本、图片和文件的捕获功能。
- **历史记录限制**：设置最大保存条目数和最大存储容量。
- **自动启动**：在设置中开启“随系统启动”选项，实现开机自动运行。
