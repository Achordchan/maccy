# Windows 上待验证清单

开发在 macOS 上做的，下面这些代码**只验证了能为 Windows 编译**（`GOOS=windows go vet ./...`），逻辑部分在 macOS 上用假对象测过，真实行为需要一台 Windows 10/11（建议虚拟机，先拍快照）。升级专项见 [`upgrade-verification-1.0.11.md`](upgrade-verification-1.0.11.md)，这里是其余的。

## 一、构建

```bash
python tools/release_go.py build --version 1.0.11
```
- [ ] 在 `artifacts/publish/win-x64/` 得到 `maccy.exe`（约 13 MB）和 `mygo-sqlite3.dll`；
- [ ] 资源管理器里 `maccy.exe` 有 Klip 图标，属性 → 详细信息里文件版本 `1.0.11.0`、产品版本 `1.0.11`、原始文件名 `maccy.exe`；
- [ ] 双击运行没有黑色控制台窗口（GUI 子系统）。

## 二、基础

- [ ] 启动后托盘有图标；`Ctrl+Alt+2` 呼出面板，失焦隐藏；第二次启动呼出已运行的那个；
- [ ] 复制文本、图片、从资源管理器复制文件，三种都被收进历史（Windows 复制文件**不带文本**，所以“先看文本”的顺序没问题，但要看一下）；来源应用显示成程序名（如 `chrome`、`Code`）；
- [ ] 连续快速复制不漏（`TestRealRapidCopies` 在 macOS 上的 Windows 对应物：`GetClipboardSequenceNumber` 在“清空再写入”时是否也只在第一步变化。如果漏，`Watcher.Retry` 已经兜底，但要看实际表现）；
- [ ] 把历史条目粘回去：文本、图片（粘到画图/聊天窗口）、文件（粘到资源管理器）；自己写入剪贴板不会被再收一遍；
- [ ] 大图（几十 MB 截图）不卡界面。

## 三、开机启动与互斥体

- [ ] 偏好设置里勾选“开机启动”：注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 出现值 `maccy`，数据是带引号的 `maccy.exe` 完整路径；取消勾选则删除；与 1.0.10 勾选的是同一项（先用 1.0.10 勾选，再用 1.0.11 打开偏好设置，应该显示已勾选）；
- [ ] 重启后自动启动；
- [ ] 程序运行时用 `Process Explorer` 或 `handle` 能看到命名互斥体 `maccy_mutex`；安装程序（覆盖安装）提示关闭正在运行的 Klip。

## 四、货架（鼠标晃动呼出）

触发：按住触发键（默认 Ctrl），在**拖着文件**时（左键按住）左右快速晃鼠标 → 光标右下方出现一个小窗口 → 把文件放进去。

- [ ] 在资源管理器里选一个文件，按住 Ctrl 和左键拖，左右晃两三下：出现货架窗口（220×220，圆角，浮在最上，**不抢焦点**，任务栏没有它的按钮）；
- [ ] 不按 Ctrl 晃，不出现；点一下就松手、轻轻抖动（不到 8 像素）不出现；按下后 0.11 秒内猛晃不出现；
- [ ] 同一次按住只出现一个；松开再按可以再出现一个，可以同时开几个；
- [ ] 把文件放进货架（拖到它上面时出现“松开以放入”）：显示图标（系统图标）、文件名；放入多个文件后窗口变大（420×420）、以列表显示、“N 档 >” 与总大小；
- [ ] 拖货架里的文件出去（单个窗口时拖图标，展开时拖某一行或 Ctrl 选的几行）到桌面、资源管理器、聊天窗口、浏览器上传框：能放下，文件没被移走（复制）；**拖出去后货架不会把它当新文件再收进来**；
- [ ] 点 × 关闭；关闭后窗口消失；
- [ ] 偏好设置里关掉“启用货架”或改触发键（Alt/Shift）立即生效，关掉后晃动不再出现（此时钩子已卸载）；
- [ ] **多显示器、不同缩放比例**（125%、150%）：货架出现在光标右下 18 像素处，被限制在光标所在屏幕的工作区内；位置、大小、字体清晰度正常；
- [ ] 以管理员权限运行的程序（如管理员终端）里拖文件时，货架是否出现（低级鼠标钩子对高权限窗口的行为）——记录结果，不要求通过；
- [ ] 用一段时间后鼠标是否有卡顿（钩子回调很短，应没有）。

## 五、同步、更新、其他

- [ ] 登录、注册、立即同步、事件流触发的自动同步（另一台设备改动后几秒内下来）；
- [ ] 偏好设置的各项；主题切换立即作用到所有窗口；
- [ ] 检查更新：见升级验证文档；
- [ ] 内存与启动时间：任务管理器里空闲内存、冷启动到托盘出现的时间，与 1.0.10 对比（目标是更省，spike 里 macOS 是 40–80 MB）；
- [ ] Windows Defender / SmartScreen 对未签名的 `maccy.exe` 与 `mygo-sqlite3.dll` 的反应。

## 六、已知限制（不算失败）

- 货架只有 Windows 有；macOS、Linux 上设置能保存但不生效。
- 货架里的图标用 `SHGetFileInfo`（按类型取），不是缩略图；图片只显示像素尺寸。
- 货架没有“钉住/取消钉住”开关（1.0.10 的 `Pinned` 只是“里面有东西”的标记）。
